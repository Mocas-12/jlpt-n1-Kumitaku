## ✨ 機能

- 🧭 **公式の大題構成に対応**：問題7 文の文法1（文法形式の判断）／問題8 文の文法2（文の組み立て·統整文）／問題9 文の文法3（文章の文法）をすべてカバー
- ⚡ **速攻テクニック集**：「接続・呼応・语气（ニュアンス）」の三線チェック、類義グループ別の高頻度文型速見表 28 項、誤り選択肢 7 分類チェックリスト、110 分の時間配分表
- 🗂 **文型ライブラリ＋暗記モード**：主流教材で公認の N1 文型を網羅した **165 項**（公式は文法リストを公表しないため、公式のテスト目標に照らして整理）。各項に接続・意味・オリジナル例文＋訳・類義辨析を付け、**高頻度 73 項**をフラグ表示。暗記モードは意味を隠してクリックで揭示、「✓ 理解」の進捗を保存、ランダム出題、各項から同族ドリルへ直行
- ⏱️ **計測つき演習**：各セットに時間目標とリアルタイムタイマー、超過は赤表示
- 🔍 **選択肢ごとの解説**：誤り選択肢には【接続不合】【近義混同】【呼応衝突】【時制不一致】【文体不合】【語序違反】【文脈断裂】のラベル、正解には接続・呼応・ニュアンスの三点説明
- 🔁 **間違いノート**：間違えた問題は自動収録、1→3→7 日の間隔反復で三回連続正解で卒業。弱点プロフィールから直接その考点の演習へ飛べる
- 📊 **タイプ別統計**：正答率バー＋演習履歴＋連続学習日数
- 🎲 **ランダム演習＆模試**：ランダム 10 問、または公式問題7〜9 の構成どおり 20 問の模試を一発で組巻（全体計測）
- 📥 **バンク拡張**：JSON を貼り付け／ファイル選択で自作セットを取り込み（同 ID は上書き）。教材を変換する AI 転写プロンプト同梱
- 📴 **PWA 対応**：manifest ＋ 最小 Service Worker。ホーム画面に追加してオフライン演習
- 🌓 **ダークモード**：システムに追従、ワンクリック切替——藍染め和紙テーマの夜間調整
- ⌨️ **キーボード解答**：1〜4 で選択、Enter で提出
- 📝 **セッション下書き**：未提出の進捗を毎問保存、誤更新でも復元
- 🧳 **記録バックアップ**：統計・履歴・間違いノートを JSON で書き出し／読み込み
- 💾 **バックエンド不要**：全データはブラウザの localStorage のみ

## 🏷️ 名前の由来

**Kumitaku（組みたく）**——「組み立てたい」から。姉妹サイト [Yomitaku](https://github.com/Mocas-12/jlpt-n1-Yomitaku)（読みたく）と同じリズム、同じ「〜たい」の造語で、公式大題「問題8 **文の組み立て**」の名前にそのまま重なる。読解は文を解体する訓練、文法は文を組み立てる訓練——解体と組立で一組だ。

デザインは Yomitaku のマンガ風和紙カード言語を引き継ぎ、朱を藍に替えた——朱印と藍染め、日本の古典的な配色の組み合わせ。

## 🔁 トレーニングループ

```
テクニック集（接続・呼応・ニュアンスの三線チェック＋文型速見）
        ↓
タイプ別演習（26 セットのオリジナル問題・計測・キーボード解答）
        ↓
選択肢ごとの解説（誤りの分類＋正解の三要素説明）
        ↓
間違いノート（1→3→7 日の間隔反復、三回正解で卒業）
        ↓
弱点プロフィール → 重点リセット → 模試で仕上げ
```

## 📚 問題バンクと著作権

内蔵バンクは **26 セット／132 問のオリジナル模擬問題**（非過去問と明記）：形式判断 60 問は類義グループ別、組み立て 48 問は公式と同じ「＊方式の統整文」、文章の文法 24 問はオリジナル文章 6 編ベース。

過去問の著作権は国際交流基金・JEES に、市販教材は各著者に帰属する。当サイトは一切含まない。手持ちの教材で練習したい場合は、JSON に転写して「真題·題库」ページから取り込むこと（AI 転写プロンプト内蔵）。

├── tests/                   # Playwright スモークテスト（19 シナリオ）

└── .github/workflows/       # CI：バンク検証 → スモーク → Pages デプロイ

## 🛠️ 開発

```bash
npm install          # 開発依存は Playwright のみ
npm run check        # 問題バンクの検証（構造・答案・正解分布）
npm test             # ローカルサーバで 19 スモークシナリオを実行
npm run hash         # アセット ?v= ハッシュと SW キャッシュ名を書き換え
npm run assets       # OG バナー／アイコンを再生成（Chromium 必要）
node tests/server.mjs 8322   # ローカル起動 → node scripts/make-screenshots.mjs
```

CI はバンク検証 → スモーク → 資産フィンガープリント → Pages デプロイの順。テストが緑でないと公開されない。

## ❓ FAQ

<details>
<summary><b>内蔵バンクは過去問？</b></summary>
いいえ。公式のテスト目標に沿って自作したオリジナル模擬問題で、「本站原创模拟（非真题）」と明記している。過去問の著作物は含まない。
</details>

<details>
<summary><b>Yomitaku との関係は？</b></summary>
同じ作者・同じトレーニングループ・同じデザイン言語。Yomitaku は読解（問題10〜15）、Kumitaku は文法（問題7〜9）。こちらで文法を固めたら、浮いた時間を読解へ。
</details>

<details>
<summary><b>学習記録はどこに？</b></summary>
ブラウザの localStorage のみ。サーバ送信は一切ない。機種変更は「真題·題库」ページのバックアップで。
</details>

## 🔒 プライバシー

- バックエンドなし・解析なし・トラッキングなし。演習データは localStorage のみ。
- 取り込んだソース URL は http(s) のみ許可、それ以外は描画時に無効化。
- Service Worker は同一オリジンのアセットのみキャッシュ。
